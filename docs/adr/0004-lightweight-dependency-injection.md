# 4. 原生轻量级依赖注入方案 (CoreDI)

- 状态: Accepted
- 日期: 2026-11-02
- 决策者: iOS 架构团队

## 背景与问题陈述

依赖注入是多模块架构解耦的核心支柱。在 iOS 生态中存在三方重型库（如 Swinject / Needle），但往往带来额外包大小、宏生成复杂性或非线程安全风险。

## 决策驱动因素

- 保持框架轻量与零三方侵入
- 完美契合 Swift 6 并发安全模型（Sendable 检查）
- 提供优雅清晰的属性包装器使用体验（`@Injected`）

## 决策结果

选定选项：在 `CoreDI` 中自主构建基于 Protocol 的轻量级容器：
- 支持单例（`single`）与工厂（`factory`）注册；
- 线程安全（并发读写锁隔离）；
- 支持在测试阶段快速置换为 Fake 实现。
