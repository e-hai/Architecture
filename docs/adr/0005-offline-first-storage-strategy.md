# 5. 离线优先（Offline-First）数据缓存策略

- 状态: Accepted
- 日期: 2026-11-02
- 决策者: iOS 架构团队

## 背景与问题陈述

移动端网络环境具有弱网、断网的不确定性。直接等待网络响应会导致首屏白屏、卡顿或不可用。

## 决策驱动因素

- 极速首屏渲染体验
- 弱网与无网状态下保证应用核心链路可读
- 统一的 Repository 数据流接口

## 决策结果

选定选项：
- 数据仓储层遵循“先取本地缓存立即发射，后拉取网络异步写入并更新”范式；
- DTO 必须经 Mapper 转换为 Domain Model 并在仓储层统一发射。
